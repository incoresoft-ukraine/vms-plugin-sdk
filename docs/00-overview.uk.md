# 00 — VMS Plugin SDK коротко

*Для технічних керівників, які оцінюють інтеграцію з VMS. Дві сторінки. Документація для
розробників починається з розділу `01`.*

## Що таке плагін VMS

Плагін розширює Incoresoft VMS зсередини. Це **один jar-файл**, у якому лежать бекенд-розширення
на Java 21 і фронтенд-бандл на Vue 3. Ядро VMS завантажує його під час роботи, без перезапуску і
без форку продукту. Користувачі керують плагінами в Admin Center або встановлюють їх із
маркетплейсу Incoresoft.

## Що плагін може

| Область | Можливість |
|---|---|
| Власна бізнес-логіка | REST і WebSocket ендпоінти на сервері VMS під захистом автентифікації VMS; власні таблиці в базі VMS; фонова обробка; очищення своїх даних стандартним механізмом ретенції |
| Власний інтерфейс | Вкладка в клієнтському застосунку з будь-якою кількістю сторінок, розділ в Admin Center, комірки відеостіни, пункти в меню "+" і в адмін-сайдбарі; усе на UI-кіті Incoresoft, тому виглядає як рідне |
| Модель безпеки | Власні права доступу, які показуються і видаються в Admin Center → Roles як вбудовані, перевіряються сервером і враховуються інтерфейсом |
| Події і правила | Нові типи правил у движку тривог: користувач налаштовує "коли X, тоді сповістити / записати / спрацювати вихід", плагін генерує тривоги й сповіщення зі своїм вмістом і власним UI деталей |
| Карти і плани | Власні типи обʼєктів на картах і поверхових планах (двері, термінали, датчики) з живим статусом і спливаючими подіями |
| Пошук | Власний тип результатів у глобальному пошуку з фільтрами, картками й деталями |
| Дані платформи | Читання камер, потоків, серверів запису, користувачів і ролей; знімки й відео навколо події |

Плагін із власною відеоаналітикою — це звичайний плагін: ваш сервер аналітики надсилає
спрацювання в плагін, плагін зберігає їх разом із камерою, а VMS додає тривоги з відео, сповіщення
й пошук. Сервер аналітики Incoresoft для цього не потрібен.

## Що потрібно партнеру

| | |
|---|---|
| Компетенції | Java 21, Maven, Guice, Javalin, SQL (jOOQ/Liquibase); Vue 3, TypeScript, Webpack Module Federation |
| Інструменти | JDK 21, Maven 3.9, Node.js 18+, інсталяція VMS 25.1 для розробки (ознайомча ліцензія від Incoresoft) |
| Бібліотеки | Публічний Java API хоста (`com.incoresoft.commons:middleware`, а також `com.incoresoft:device-driver-sdk` для плагінів, що працюють з камерами/пристроями) у Maven Central і UI-пакети `@incoresoft/incoresoft-ui`, `-icons` та `-toasts` у публічному реєстрі npm; нічого налаштовувати не треба |
| Пакет SDK | Ця документація і повний приклад плагіна у вигляді двох шаблонів (бекенд і фронтенд) |

## Шлях від ідеї до клієнтів

1. **Старт** — партнер отримує доступи, пакет SDK і dev-інсталяцію VMS.
2. **Каркас** — копіює два шаблони, перейменовує, запускає проти dev-VMS (перший видимий
   результат менш ніж за годину).
3. **Розробка** — збирають jar і завантажують його в dev-VMS через Admin Center; нова версія
   замінює попередню без перезапуску VMS, дані й правила плагіна зберігаються. Хост сам знаходить
   інтерфейс плагіна.
4. **Пакування** — один `mvn package` дає jar із фронтендом усередині.
5. **Постачання** — jar передається клієнтам: вони встановлюють і оновлюють його в Admin Center
   (Settings → Marketplace → Extra Settings → Install Plugin from Disk) або через API. Розміщення в
   маркетплейсі Incoresoft, з установкою й оновленням в один клік, узгоджується з Incoresoft.

## Правила гри

* **Одна серія версій плагіна на одну лінію релізів VMS.** VMS 25.1 приймає плагіни версій
  `25.1.x`; нова лінія VMS (наприклад 26.1) потребує перезібраного і переверсіонованого плагіна.
  Бібліотеки SDK йдуть тими ж лініями, їхній API зберігає бінарну сумісність у межах лінії.
* **Плагіни працюють у процесі VMS з повною довірою.** Це дає їм силу, і саме тому Incoresoft
  переглядає плагіни перед публікацією, а від партнерів очікує дотримання конвенцій SDK щодо
  маршрутів, прав і ресурсів.
* **Ідентифікатори обираються один раз.** Id плагіна, назва модуля і id прав стають частиною
  даних клієнта після першої установки і мають лишатись незмінними.
* **Мови.** UI-фреймворк підтримує англійську, українську та іспанську; плагін постачає власні
  переклади.
